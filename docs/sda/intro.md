## Introducción

Este módulo presenta una guía técnica para la creación y configuración de un Data Advisor utilizando Daiana Studio. Explora los componentes principales de un flujo de agentes, tales como el Supervisor, los Workers especializados, el manejo de memoria y la integración de herramientas y bases de conocimiento, brindando las bases para implementar un esquema de orquestación estructurado y escalable.
